Cómo entra su trabajo al repo del ideathon

El repo que crearon por su cuenta es el cuaderno. El entregable es el Lean Canvas y el pitch, en un Pull Request desde un fork de este repo.

  1. Abrir github.com/MarxMad/Ideathon-Stellar-BAF-Canacintra
  2. Arriba a la derecha: Fork → Create fork
  3. La URL debe decir github.com/SU-USUARIO/Ideathon-Stellar-BAF-Canacintra
  4. En ese fork: Add file → Upload files. Suben lean-canvas.md y pitch.md a ideas/equipo-07-nombre-corto/ (minúsculas, guiones, sin acentos)
  5. Commit changes
  6. Contribute → Open pull request hacia el repo original
  7. Título: Equipo 07 — Nombre de la idea
