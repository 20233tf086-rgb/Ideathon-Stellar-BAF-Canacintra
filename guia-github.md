# GitHub para el ideathon

Todo se hace desde el navegador. Un fork por equipo. Entregables: Lean Canvas y pitch.

---

## 1 · Fork

1. Abre [github.com/MarxMad/Ideathon-Stellar-BAF-Canacintra](https://github.com/MarxMad/Ideathon-Stellar-BAF-Canacintra).
2. Arriba a la derecha: **Fork** → **Create fork**.
3. La URL debe decir `github.com/SU-USUARIO/Ideathon-Stellar-BAF-Canacintra`.

Si no aparece Fork, verifica el correo de GitHub (y el spam).

---

## 2 · Subir canvas y pitch

1. En **ese fork:** **Add file** → **Upload files**.
2. Suben los dos archivos a:

```
ideas/equipo-07-nombre-corto/lean-canvas.md
ideas/equipo-07-nombre-corto/pitch.md
```

Minúsculas, guiones, sin acentos. Plantillas: `plantillas/lean-canvas.md` y `plantillas/pitch.md`.

3. **Commit changes.**

Para que el resto del equipo también suba archivos: *Settings → Collaborators → Add people*. Cada quien acepta la invitación.

---

## 3 · Pull Request

1. **Contribute** → **Open pull request** hacia el repo original.
2. Base: `MarxMad/Ideathon-Stellar-BAF-Canacintra`. Head: el fork de ustedes.
3. Título: `Equipo 07 — Nombre de la idea`.
4. **Create pull request.**

---

## Problemas comunes

| Síntoma | Qué hacer |
|---|---|
| No hay botón Fork | Verificar el correo de la cuenta. |
| “You don't have permission” | Estás en el repo original. La URL debe llevar tu usuario. |
| El compañero no puede subir | Falta aceptarse como Collaborator. |
| Se borró el texto | Pestaña **Commits** del fork: ahí está cada versión. |
