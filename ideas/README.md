# Ideas

Cada equipo crea **una carpeta** aquí y sube el Lean Canvas y el pitch.

```
ideas/equipo-07-nombre-corto/
├── lean-canvas.md
└── pitch.md
```

Número de equipo y un nombre corto. **Minúsculas, guiones, sin acentos ni espacios.**

Copien [`../plantillas/lean-canvas.md`](../plantillas/lean-canvas.md) y [`../plantillas/pitch.md`](../plantillas/pitch.md).  
Ejemplo de detalle (no copien el contenido): [`equipo-00-ejemplo/`](equipo-00-ejemplo/).
